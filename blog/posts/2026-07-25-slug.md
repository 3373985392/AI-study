## System Prompt（系统提示词）

System Prompt 是对话开始时给模型的**角色设定**和**行为约束**。

- 它告诉模型"你是谁"和"你应该怎么回答"
- 用户看不到 System Prompt，但它影响整个对话的走向
- 比如：`你是一个专业的 Python 后端工程师，回答要简洁，使用中文`

## Temperature（温度）

Temperature 控制模型输出的**随机性**，取值范围 0-2：

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 0 - 0.3 | 输出确定、几乎每次相同 | 代码生成、事实问答 |
| 0.5 - 0.7 | 平衡创造性和准确性 | 通用对话、翻译 |
| 0.8 - 1.2 | 创意丰富、多样性高 | 文案写作、头脑风暴 |
| > 1.5 | 容易胡说八道 | 不推荐 |

## Token（令牌）

Token 是模型处理文本的**最小单位**。

- 1 个中文字 ≈ 1-2 个 Token
- 1 个英文单词 ≈ 1-2 个 Token
- 模型的上下文窗口（Context Window）以 Token 计数
- 比如 GPT-4 的 128K 上下文 ≈ 约 10 万中文字

### 为什么 Token 重要？

1. **计费**：API 按 Token 数量收费
2. **限制**：超过上下文窗口的内容会被截断
3. **优化**：Prompt 的长度直接影响成本和响应速度

## 关键认知

理解这三个概念是做 AI Agent 开发的前提——System Prompt 决定了 Agent 的行为边界，Temperature 影响回复质量，Token 关系到成本和上下文管理。
